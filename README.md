Toku App 🎌

A Simple Japanese Learning App

Toku App is a beginner-friendly Flutter application designed to help users learn basic Japanese vocabulary. The app features four essential categories:
Numbers 🔢
Family Members 👨‍👩‍👧‍👦
Colors 🎨
Common Phrases 💬

Each category includes audio pronunciations to enhance the learning experience. This project is built with Flutter and follows clean UI design principles.

🚀 Features:
✅ Easy-to-use interface
✅ Audio support for pronunciation
✅ Engaging visual design

🛠️ Tech Stack:
Flutter (Dart)
Clean UI with Material Design
